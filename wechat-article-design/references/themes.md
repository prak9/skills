# 主题选择与自定义

主题只改变视觉角色，不改变文章内容和组件语义。内置主题的唯一实现来源是 `scripts/render_wechat.py`；本文件负责选择规则和自定义主题契约。

## 内置主题

| ID | 中文气质 | 适合内容 | 视觉策略 |
|---|---|---|---|
| `ink` | 墨蓝刊读 | 行业分析、专业观点、科技评论 | 冷静墨蓝、细边线、编辑式编号、克制浅底 |
| `moss` | 苔绿笔记 | 教程、清单、方法论、工具测评 | 温和苔绿、清晰步骤、低饱和提示块 |
| `paper` | 暖纸随笔 | 人物、文化、旅行、生活与情感随笔 | 暖白纸色、棕褐点睛、较松段落节奏 |

用户指定主题时直接采用。没有指定时按文章的主导阅读任务选择，不按单个关键词机械匹配。用户要求直接出结果时选一套，不再询问；只有品牌气质或审美方向确实不明确时才生成两个短样稿供比较。

## 层级规则

所有主题共享同一信息架构：

1. 标题是全文唯一一级视觉锚点。
2. `##` 章节按出现顺序编号，编号只帮助导航，不替代标题。
3. `###` 用轻量左边线建立局部层级。
4. 正文以灰阶和留白承重；显式 `**加粗**`、`==高亮==` 和引用才进入强调层。
5. 引用、列表、代码和图片各用一种稳定组件，不随机换皮。

不要自动给每段添加关键词下划线。只有用户明确要求编辑性标注时，才从原句中选择少量完整短语，并保证不改变语义。

## 项目级自定义主题

需要品牌配色时，在用户项目或交付目录创建 JSON 文件，而不是修改 skill。JSON 可以只覆盖需要调整的键，其他值继承 `ink`：

```json
{
  "name": "雾海蓝",
  "accent": "#416B7A",
  "accent_dark": "#244653",
  "accent_soft": "#EAF1F3",
  "text": "#202A2E",
  "muted": "#68777D",
  "surface": "#F6F9FA",
  "border": "#D5E0E4",
  "canvas": "#FFFFFF"
}
```

允许键只有：`name`、`accent`、`accent_dark`、`accent_soft`、`text`、`muted`、`surface`、`border`、`canvas`。颜色必须是六位十六进制。渲染器会检查正文色与画布、深强调色与浅强调底的对比度；不通过就调整色值，不要绕过检查。

从参考图生成主题时只提炼可描述的设计变量：冷暖、明度、对比度、边角、留白和信息密度。不要复制参考图中的 Logo、专有图形、文字、人物或独特版式。先生成 JSON，再用同一篇短样稿渲染预览，确认后才排全文。
