# 高频预测到盈利：瓶颈诊断

适用于 py 高频期货的信号、SIM、实盘及成交代理残差分析。选择能回答问题的层次，不要求每次生成完整报告，也不因分析授权而重训、回放、落盘或修改生产。具体账表字段与配对边界见同目录 `deep-attribution.md`。

## 五层问题及可辨认边界

| 层次 | 观察什么 | 避免的误判 |
|---|---|---|
| 预测优势 | 原标签 IC、延迟 IC、方向 markout、门槛附近及强信号分箱 | 标签 IC 为正不等于成本后可交易优势 |
| 独立机会代理 | 时间降采样、连续同向事件簇、跨日/行情段收益集中度、品种收益相关性 | tick、因子、订单、MC 路径数不是独立 BR |
| 持仓转化 | 成交后方向收益、首次反向信号、重试、反手时延及实际退出 | 仓位相关性不是原理论 TC；未成交反向单不自动等于亏损根因 |
| 成本 | 成交价格桥、显式费用、换手及重复反手 | 成交价已含的 spread/滑点不再重复扣除 |
| 净收益分布 | 每手收益、盈亏比、分位数、尾部贡献、日收益与回撤 | 单日、单路径或抵消后总差接近零不证明稳定性 |

行情条件贯穿各层：品种/session、方向、开盘与非开盘、振幅、净变振幅比、趋势效率。先核对已有字段定义与采样尺度；分组只是观察性诊断，不自动成为过滤或交易规则。不要把 EG 某一日等历史案例固化成其他品种的先验结论。

## 从信号到可交易优势

分开统计全 tick、越过 fee-gate、产生委托意图、最终成交四类总体，保留未成交与部分成交。原标签与诊断 markout 可以不同，须注明各自目标和单位。

延迟曲线可定义为 `IC(h,d)=Corr(s_t, (m[t+d+h]-m[t+d])/m[t+d])`。按问题预先选择少量 h、d；tick 和秒不混用，同时报告实际经过时间。当前 tick 的可交易性须满足事件先后，未来行情仅用于事后标签/诊断，不能偷偷进入线上信号。仿真成交代理若明确允许使用报单后路径，须标明这是离线代理信息，不宣称线上可用。

跨休市、行情缺失或期限不完整时标无效，不缩短窗口补齐。训练确定分箱、预处理及参数，再看样本外门槛附近和尾部的方向收益、成本覆盖及样本数。全样本 IC 改善但尾部未改善，优先考虑选择/目标错配，不直接宣称交易能力提高。

## 事件与持仓路径

先核对该版本真实交易规则。项目常见非多即空、反向平仓并开仓时，应追踪：

`反向信号 → 委托/重试 → 未成交/部分/全成交 → 原仓平掉 → 新仓建立 → 后续价格收益`。

核对实际生效时点的仓位，而不是用意图方向代替持仓。部分反手可以经历中间库存状态；持仓上限不是每单成交量上限。缺稳定决策 ID、模型身份或真实成交时间时，只能做近邻 cohort、时间敏感性或区间界限，不能把同秒兼容当精确配对。用共同仓位锚观察之后路径，仍不等于因果隔离。

固定成交事件及单位数量，可比较固定期限 markout 与实际退出收益；对照期限须有事前理由，不能事后挑最优退出。它只用于定位：重叠事件不能直接加成可实现收益，延长持有也会改变风险和后续机会。只有完整策略回放才能检验净效果。

## 账目与评价

统一初末库存、事件顺序及 mid 基准后核对：

`净收益 = M × Σ(q_t × Δmid_t) + 成交价格桥 − 显式费用`。

成交价格桥含成交现金相对同口径 mid 的差，须含必要的期初/期末估值。现金闭合不是原因闭合。MC 每路径先独立闭合，再汇总净收益；不能将均值伪装为一条交易轨迹。额外路径只增加数值精度，不增加独立市场观察。

- **成交代理准确度：**核心展示平均每成交手净收益的有符号偏差与绝对误差，单位 tick；明确分母是否开平双边成交手数，并展示 SIM/REAL 各自手数及数量误差。零成交时指标缺失而非零。另报窗口盈利 MAE/RMSE、成交率误差及 MC 分布。不要把逐窗比率均值和按手数汇总比率混用。
- **信号或交易规则价值：**成本后每手收益、POT，辅以 costcov、dret、tn、日收益与回撤；遵守已确认评价合同，不用 IC、Brier 或更好成交率替代盈利验收。
- **尾部：**展示正负收益总额、最大及前三大交易贡献、均值/中位数、胜率与盈亏比。删除最佳/最差交易只作敏感性，不作新的策略成绩；不以实际净收益接近零时爆炸的相对误差作为唯一判断。

分窗口、分 session 保留，不仅看抵消后的合计。少量交易和多次使用的开发窗口不支持独立验证；依赖按日期/事件簇组织，不把重叠标签当独立样本。

## 按证据决定下一实验

| 观察 | 优先检验的竞争解释 |
|---|---|
| 原标签 IC 好，延迟后 markout 消失 | 期限/目标错配，或执行延迟与成交选择 |
| 全样本好，门槛尾部弱 | 尾部尺度失配，或状态组成/样本选择不同 |
| 成交后有优势，实际持仓收益弱 | 退出/反手路径损耗，或固定期限对照的事后选择与风险增加 |
| 毛收益好，净收益弱 | 费用、成交价格桥、重复换手，而不是笼统称模型差 |
| 总量接近，收益仍差 | 方向/时点/持仓路径不对；总量匹配不等于过程真实 |
| 依赖极少数盈亏尾部 | 独立机会不足、行情状态覆盖有限，或可重复的条件优势 |

先冻结已有模型与预测做低成本诊断；证据支持后才在授权内实验。退出实验保留基线与固定信号、成交模型、费用、仓位及种子，明确改变的规则。开发选择与 fresh 验证分开；不自动新增窗口、访问 holdout 或部署。结论回答：观察到什么、哪些解释获支持、还不能区分什么、什么实验会推翻当前判断。证据不足可以是最终结论，不强行归因。
