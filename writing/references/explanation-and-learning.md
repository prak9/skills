# 解释与主动学习

解释本身通常不需要独立 Skill。只有写作交付确实存在受众、类比或理解检验难点时使用本参考。

根据读者已知与目标，选择最小的理解桥梁：具体任务或例子 → 实际机制 → 必要术语或正式模型 → 容易混淆的边界。代码可跟踪一个真实输入的状态变化；公式先解释变量改变时结果为何变化。类比是桥梁，不是证据，应说明失效处，避免多重比喻替代机制。

读者要求练习或主动掌握时，用预测、反例或迁移任务检查其模型：改变一个条件后能否判断结果，比流畅复述更能说明理解。按需给提示与反馈，不把直接解释变成强制测验，也不因完成产物就宣称掌握能力。

保留技术真实和不确定性，省略熟悉背景，展开必须由读者补齐的关键一步。达到请求的理解目标即可收束，不自动加测验、下一课或泛泛邀请。
