# Sharpen

Make the user's task **deeper, not bigger**, then rewrite the prompt so it executes at a top-practitioner bar.

Before rewriting the prompt, answer four questions concisely:

1. **Missing depth:** what a top professional in this field would do here that the user is not asking for.
2. **Rawest material:** the primary, rawest source material they would start from instead of already-digested summaries.
3. **Specific methods & tools:** the concrete techniques, probes, or tools they would actually run.
4. **External proof:** what—other than you or the user—would objectively show the result is right.

Then rewrite the prompt to ask for exactly that. Have the rewritten prompt instruct the agent to **prototype any choice an experiment can settle** and recommend an option based on observed evidence, while leaving product or preference choices that no experiment can settle for the user to make.
