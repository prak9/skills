# 判断校核伙伴：来源、设计与初次验证

日期：2026-11-14。本轮只新增此 Skill；不修改现有 decision、socratic-tutor 或 Invest 的未提交内容，不运行交易、真实HFT实验、Notion归档或外部部署。

## 原视频提取与边界

来源：[真正拉开差距的，是独立判断](https://www.xiaohongshu.com/explore/6af826be000000002601091b)，笔记作者阿水财经笔记。视频约584.7秒。已读取全时间轴中文画面字幕，检查全部100个所选场景帧，重点复看Agent部分的中英字幕；未做音频ASR，不声称无字幕口语也被完整转写。本地取样2fps共1169帧。首次窄条OCR因宽高比触发单行识别而未提取到文字，修正为启用文本检测后保存独立v2证据，得到266组含重复/噪声的中文字幕；失败输出保留，不把它当作视频没有内容。

前半段讨论资本配置、建设者与中介激励；开头承认自身观点可能反映偏见或不安全感，重要决策需要对过去错误复盘。07:09开始强调独立判断，认为信息环境变化要求人更多地自行辨别。08:04左右对特定模型的可靠性评价是讲者个人意见，不是本轮验证过的比较结果。

用户指定的智能体段落在约08:15—08:44：讲者描述把整篇文章交给自用Agent，使它能站在话题的不同立场、来回交锋，呈现观点并提炼细致结论。09:24以后强调给头脑干净的输入，让人自己思考。视频没有公开其Prompt、代码、角色数、工具权限或有效性评测；本Skill是对使用方式的自主工程设计，不是取得或复刻对方实现。

可吸收的是“把判断暴露给最强竞争解释，并回到可查证据”。不能据此推出辩论自动产生真相、模型投票等于独立确认、取双方中点就是公允。三种职责是本次设计添加，不是视频明确提出三个Agent。

## 用同一标准检查视频自身

约06:04—06:37的市值迁移概率与组合仓位叙述，可以作为本Skill的应用演示，而不是默认投资规则。仅本片未给出样本、时间跨度、起点、退出/退市处理、数据选择和估计不确定性；这些概率尚不能核实。即使某个条件迁移概率成立，也不能单独推出给定仓位：买入价格、回报/损失分布、相关性与资金约束仍缺失。

同样，对过去新闻更客观、中介低效或某模型更可靠等说法，应作为可检验的具体主张，不因讲者坦诚反思就免于证据核查。本轮未就这些外部历史/金融事实展开验证；没有把它们写成Skill结论。以上为作者审计示范，不计入Agent前向测试。

## 职责边界与增量

`decision`负责真实行动与承诺选择，`socratic-tutor`负责用户明确要求的学习练习。本Skill负责已有判断或文章主张的证据校核，不替代这两者，也不自动追加完整投研或课堂。默认一个Agent承担解释、竞争解释、裁决职责；分离上下文需要实际授权，模型数和身份不等于独立性。

## 实际验证

[cases.jsonl](cases.jsonl)在候选入口写入前保存6个可见开发场景、23项语义条件。执行者 `/root/judgment_audit_forward` 使用单个独立上下文批量作答，只收到题目与两份指令，不收到评分标准；[原始回答](forward-responses.md)保留。主控作者按预先条件逐项评分，6/6场景、23/23条件满足；不是第三方盲评，也不是6次独立上下文、基线消融或人的判断能力测量。

| 场景 | 实际表现 |
|---|---|
| 成功子集的速度翻倍 | 复算1与2任务/小时，识别分母不同，要求完整任务/失败成本，不认定欺诈 |
| 显著性观点的折中 | 不平均两方；区分预注册主分析、后验子组与效应大小 |
| 三Agent同源 | 指出同一匿名帖仍是一条底层消息，不以用户数推出利润，也不反推亏损 |
| 充分证据正例 | 接受给定口径下12/12=100%，不凭空造反方或外推未来 |
| 偏好与事实 | 认可可逆性偏好的条件性，不捏造概率或诊断用户偏见 |
| 纯改写负例 | 一句话完成，不强制辩论、查询、教学或投研 |

入口校验通过，30项仓库合同检查及1项路径卫生检查通过。它们检验结构与路径，不证明判断更准确。执行者报告未读取外部资料、写外部系统或启动实验；这是自报范围，不是宿主侧审计。其模型/推理设置继承会话，未获得独立资源用量，不能宣称更省token或更快。
