# 可选基础层调用契约

适用于投研或其他上层 Skill 已形成关键判断，需要专项质询时。这里是自然语言任务契约，不是运行时 API、后台服务或固定多 Agent 编排。调用者须允许此交接；它原本禁止调用其他 Skill 时，不以本契约绕过该限制。

## 最小输入

交接已有上下文即可，不为填格式重复搜集材料。一个任务可含少量相互关联的主张，各有稳定标识；只有股票代码而没有待审判断时，先形成具体主张，不把整家公司研究隐式交给基础层。

```yaml
任务: cloud-owner-cash
主张: 云业务增长将在未来三年持续提高每股股东现金流
范围: 公司、证券权益、期间、币种及数据截止日
证据: 原始来源标识、日期、位置、相关摘录或模型输入
前提与竞争解释: 已有假设、已知反证；没有则标记未提供
审计目的: 检验基准情景的现金转化假设
边界: 可用工具、补查范围与预算；不交易、不外部写入
```

优先使用交接证据；只补查可能改变结论的缺口，不重新做完整投研。保留来源标识、版本、首次可得日期、口径、单位和不确定性；计算结果回链到输入。来源无法取得时明确核验范围，不把第三方转述变成已核实事实。

## 逐项返回

| 字段 | 要求 |
|---|---|
| 主张标识与判定 | 支持／条件成立／被反驳／未能判定；指明范围 |
| 决定性证据 | 原始来源位置、必要复算；哪些证据不能重复计权 |
| 竞争解释与回应 | 最强替代机制、支持方回应、仍存活的分歧 |
| 承重缺口 | 哪个未知最可能改变结论；没有则不凑数 |
| 更新条件 | 能区分解释的观察、方向或有依据的阈值、来源 |
| 上层影响 | 哪项假设应保留、收紧或重建；是否需要重算 |

不强制总分、概率或对称篇幅。若调用者要求概率更新，区分先验、证据在竞争解释下的出现可能性及新增信息；不能识别似然比时不编造数值，也不把已使用的证据再乘一次。结论与复算是公开可审计论证，不是内部思维链或角色对话实录。

调用者负责将结果并入原模型，重算情景概率、估值及建议，并检查假设的一致性。审计不直接决定目标价、仓位或外部执行；也不保证相反观点都已被穷尽。沿用原任务记录中的主张、截止日和未决项，不建立第二套记忆库。

## BABA 示例：检验增长到股东回报的桥梁

以下为方法示例，不包含当前 BABA 财务事实或投资结论。

支持解释：云收入和增量经营利润改善，投入期结束后形成更多股东现金。竞争解释：增长依赖持续设备投入、价格竞争或融资，收入改善未能转为每股现金。

核查收入口径与客户需求、增量利润、资本开支及设备更新、营运资本、股权激励和净稀释。不能把会计利润、经营现金流和股东自由现金流混为一谈；同一管理层说法被多家媒体转述仍只是一条底层证据。

若给定材料只有收入增长，合格返回是：收入主张在其口径内可获支持，但现金转化主张尚未判定；需要将增量利润与维持/增长投入、营运资本和稀释衔接，调用者据此保留不同现金转化情景。既不由收入增长推出值得买，也不因证据缺失断言价值陷阱。

若现金转化已有可比期间的充分证据，应在该范围内接受，不为了左右互搏捏造反方；未来持续性仍由竞争与投入假设决定。没有新增证据、承重前提或模型影响时停止，交回未决项而不是继续辩到一致。
