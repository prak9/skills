# 因果分析：从观察变化到可行动解释

当方案排序取决于“某项干预到底造成了什么”时，不能把前后变化直接当成干预效果。使用这条循环：

```text
现实观察
  -> 分析：拆开结果和候选机制
  -> 解耦：定义反事实并隔离目标效应
  -> 抽象：保留可迁移的变量关系
  -> 重新耦合：放回中介、交互与反馈
  -> 与现实比较并修正
```

目标不是给所有因素列一张清单，而是形成一个带证据边界、能够被后续观察推翻、并能改变行动的解释。

## 1. 先冻结因果问题

先写清最小因果契约：

```text
决策：这个判断会改变什么行动？
对象与时间：对谁、在哪段时间？
干预 T：究竟改变了什么，何时开始？
结果 Y：销量、销售额、毛利还是长期留存？单位是什么？
目标效应：要估计总效应、直接效应，还是某个群体中的效应？
反事实：同一对象在同一时期没有接受 T，本来会怎样？
```

先选对结果。销售额、销量、利润和顾客价值不是同一个目标；一个指标上涨不能替另一个目标回答问题。默认优先估计决策最关心的**总效应**。只有直接效应会改变行动且中介能够被合理识别时，才进一步拆直接与间接路径。

因果效应关心的是同一目标对象的两个潜在结果之差：

```text
效应 = Y(接受干预) - Y(未接受干预)
```

现实只能同时观察其中一个，因此“反事实从哪里来”是整个分析的承重问题。

## 2. 分析：先展开混沌压缩

从结果的会计恒等式开始，确认观察变化究竟落在哪一层。例如：

```text
销售额 = 平均成交价格 × 销量
销量 = 客流 × 转化率 × 每笔购买量
利润 = 销售额 - 变动成本 - 固定成本
```

恒等式用于定位变化，不自动证明原因。`销售额上升` 可能来自价格、数量或产品组合，也不等于需求、利润或顾客价值上升。

然后按时间和角色画最小机制图：

- **干预 T**：正在评估的变化，如涨价。
- **结果 Y**：真正要解释的指标。
- **先于干预的共同原因 C**：同时影响是否实施 T 和 Y，可能形成混杂。
- **同期冲击或共同干预 K**：与 T 同时发生并影响 Y，如返校、促销、竞品停业。
- **中介 M**：T 之后被改变、再影响 Y 的路径，如涨价改变顾客结构。
- **调节因素 Z**：使效果因群体、渠道或时期而不同，如价格敏感度。
- **反馈 F**：结果反过来改变后续行为，如客流减少后排队缩短，部分需求回流。

每条候选路径至少写出方向、先后顺序和可观察信号。只列“价格、天气、促销、产品”不是机制；“促销先增加到店客流，因此未涨价时的 8 月销量也可能高于 7 月”才是可检验解释。

## 3. 解耦：把观察差异改写成反事实差异

不要混淆两种差异：

```text
观察变化 = 8 月实际结果 - 7 月实际结果
目标效应 = 8 月涨价后的结果 - 8 月未涨价时本会出现的结果
```

前者可以直接计算；后者需要识别设计。先列出与 T 同时变化的因素，再选择能近似反事实的最轻方法：

| 证据设计 | 反事实来源 | 通常可支持的结论 |
|---|---|---|
| 随机对照或可信 A/B | 同期随机未处理组 | 在实验范围内的平均因果效应 |
| 分阶段上线、自然实验 | 规则造成的同期可比组 | 在关键识别假设下的局部因果效应 |
| 差分中的差分、合成对照 | 处理前趋势相近的对照 | 在平行趋势等假设下的效应 |
| 中断时间序列 | 干预前趋势和季节模式 | 在同期无其他结构突变等假设下的效应 |
| 匹配、分层或回归调整 | 已观测且可比的协变量 | 在无未观测混杂等强假设下的估计 |
| 单组前后对比 | 上一时期 | 观察性变化，不能单独识别因果 |

只采用当前决策所需的最低充分设计，并明确其识别假设、样本边界和可能破坏假设的事件。无法构造可信反事实时，把结论降级为“相关”“机制假设”或“未解决”，不要用模型复杂度制造确定性。

调整变量前先看时间顺序。估计总效应时，不能把干预造成的中介当普通控制变量消掉；也不要条件化在干预和结果共同造成的选择变量上，否则可能引入新的偏差。

## 4. 抽象：从故事提炼生成结构

抽象不是删除细节，而是删除不影响目标效应的具体名词，同时保留方向、时间、单位和关系：

| 具体事件 | 可迁移角色 |
|---|---|
| 店铺涨价 | 目标干预 |
| 学生返校 | 外部需求冲击；若也影响定价，则可能是混杂因素 |
| 新调料上线 | 产品吸引力变化或共同干预 |
| 同期促销 | 营销共同干预 |
| 顾客结构变化 | 中介或效果异质性的来源 |
| 8 月 | 时间、季节和制度环境 |

将具体故事压缩成一个生成结构，而不是无方向的变量列表：

```text
Y = f(T, C, K, M, Z; 环境)
T -> M -> Y
T × Z -> Y
Y_t -> F -> Y_t+1
```

分析是从整体展开到具体因素；抽象是从具体因素重新压缩到少数稳定关系。前者减少遗漏，后者产生可迁移模型。第二次压缩必须保留哪些变量先发生、通过什么路径起作用，以及哪些关系可能随环境改变。

## 5. 重新耦合：解释实际结果如何共同生成

把为了识别而暂时隔离的因素放回系统，并分别检查：

1. T 对 Y 的直接路径；
2. 经由中介的间接路径；
3. T 与季节、群体或渠道的交互；
4. 顾客、竞争者和组织行为产生的反馈；
5. 会计口径能否闭合，是否存在未解释残差。

需要贡献桥时可以写成：

```text
实际结果
= 基线反事实
+ 各项已识别效应
+ 交互效应
+ 未解释残差
```

但这是一座**因果桥**，不是把相关变量任意相加。各项必须来自兼容的识别设计、使用同一对象和单位，并避免把总效应与其内部中介重复计算。非线性或交互系统的贡献分配还可能依赖分解顺序和模型设定，必须披露口径，不能把其中一组数字写成唯一答案。无法单独识别的贡献要合并、给区间，或标为未解决。

重新耦合后的解释应能容纳表面矛盾。例如“总销量上升”与“涨价本身压低销量”可以同时成立：同期需求冲击的正效应大于价格的负效应，最后才表现为净增长。

## 6. 用证据标签约束语言

给关键句标注最强可支持等级：

- **观察事实**：原始数据直接显示。
- **会计推导**：由定义或恒等式复算得到。
- **相关诊断**：变量共同变化，但因果方向未识别。
- **因果估计**：反事实来源、识别假设和范围均已说明。
- **机制假设**：有方向和可观察预测，尚待验证。
- **未解决**：现有数据不能区分主要解释。

语言不得越过证据等级。“与……一致”不能写成“由……造成”；单次前后变化不能写成已识别的干预贡献。

## 7. 闭合为验证循环

每个关键解释都要产生下一步观测：

```text
机制假设：
若它成立，应先看到：
最强替代解释：
能区分二者的最小证据：
推翻条件：
结果会改变的行动：
```

优先使用同期对照、错峰或小范围试验；不能试验时，寻找自然边界、历史基线、负对照和敏感性分析。将新数据与预测比较，更新结构，再重复“分析—解耦—抽象—重新耦合”。如果任何可能结果都不改变决定，停止扩展模型。

## 8. 决策输出模板

当因果判断承载方案排序时，在常规决策报告中增加：

1. **结论与边界**：当前能说什么、不能说什么，置信度如何。
2. **问题与目标效应**：T、Y、对象、时间、总效应或直接效应。
3. **观察分解**：会计恒等式、各组成部分的实际变化。
4. **最小因果图**：共同原因、同期变化、中介、调节与反馈。
5. **反事实与识别**：比较组或基线来自哪里，依赖哪些假设。
6. **重新耦合解释**：各路径、交互、残差及其证据标签。
7. **决策含义**：判断如何改变推进、规模、定价或停止选择。
8. **下一步验证**：最便宜的区分性证据、预期信号与推翻条件。

## 9. 烤肉店示例的正确结论形态

若单价从 10 元升至 12 元，销量从 100 份升至 120 份，只能直接确认销售额从 1000 元升至 1440 元，且价格与销量都发生了观察性变化。它尚不能回答“涨价使 8 月销量或销售额改变了多少”。

如果目标是销量效应，应比较“8 月涨价后的销量”与“同一个 8 月未涨价时本会出现的销量”；如果目标是销售额效应，还要同时纳入价格的机械变化和销量路径。返校、新产品和促销提供了竞争性解释。只有同期可比门店、顾客随机分组、错峰涨价或有充分假设支持的时间序列等证据，才能近似未涨价的 8 月。

因此在反事实尚未识别时，合格结论是：“8 月总结果上升，但涨价本身的方向和幅度未解决；先用可比组或错峰试验估计效应，再决定是否复制涨价。”不能写成“涨价已被证明有效”。
