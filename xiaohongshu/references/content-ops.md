# 组合运营任务

组合的是已授权能力，不是扩大权限。先确定问题、目标账号/主题、时间范围和需要交付的结果；可查信息自己补齐，不要求用户逐项填表。

- **竞品分析**：搜索和主页定位样本，读取正文与实际封面/图片，比较受众、选题、标题承诺、内容兑现、证据、结构、互动。记录链接、采集时间与抽样方法；点赞数不是曝光、转化或因果效果。
- **热点追踪**：同一关键词比较“最新”和高互动样本；区分当前可见排名、历史累计热度与有多期观测支持的趋势。一次搜索不能证明增长率或全平台热榜。不默认建定时任务。
- **创作流程**：明确读者和表达目的 → 研究可验证素材 → `writing` 生成原创草稿 → 用户确认 → 在已授权时进入发布。仅要选题/草稿就止于本地交付。
- **互动管理**：先给相关评论建议、目标和理由；用户指定范围与批准文本后才发送。点赞收藏并非默认附赠步骤。

根据问题采用短文或表格，不强制每项都写表，不强制每个只读步骤等待确认。没有统一“最佳发布时间”或安全日评论配额；如需优化，用用户自己的合法数据设可比较实验，不能从上游经验值直接下结论。

输出交代做了什么、依据哪些具体笔记、哪些只是推断、未获取内容及下一步。严禁用漂亮总结掩盖正文/图片没有读到。
