# Composition And Taste

Use this reference to turn content and user intent into a visual direction without falling back to a generic page template.

## Frame The Interface

Answer privately before choosing components:

- Who is the primary user, and what are they trying to decide or accomplish now?
- What must be understood in the first viewport?
- What is the strongest supported value, relationship, or action?
- What evidence, context, or caveat earns trust?
- Which material belongs in the fast path, and which can remain available for audit?

Order the interface by user need, not source-document order. Each section should answer a new question. Give each claim one primary home instead of repeating it as a hero, card, chart, and conclusion.

## Compare Real Directions

When the design is open-ended, form 2 hypotheses that differ in structure:

| Dimension | Direction A | Direction B |
|---|---|---|
| Opening | claim, action, evidence, comparison, or object led | a materially different lead |
| Topology | editorial flow, split, canvas, timeline, tool, ledger, etc. | a different spatial model |
| Density | concentrated proof with quiet support | another deliberate rhythm |
| Interaction | direct manipulation, progressive disclosure, or none | a different user path |
| Organizing move | one content-specific geometry | another content-specific geometry |

Choose the direction that reduces interpretation and action cost. A palette swap is not a different direction.

## Map Meaning To Geometry

- Magnitude or rank: aligned position or length on a common scale.
- Change over time: ordered position on a shared time axis.
- Composition: proportion of a whole.
- Threshold or range: distance from a visible boundary.
- Process or dependency: connection and sequence.
- Qualitative alternatives: aligned rows or intentionally contrasted columns.
- Exact lookup: semantic table.
- One conclusion: concise prose.

Use a chart only when the relationship becomes faster to understand visually. Show units, periods, populations, baselines, uncertainty, and a text or table alternative when the data matters.

## Create Hierarchy Before Decoration

1. Set content order and source order.
2. Choose the dominant object and shared alignment grid.
3. Establish type roles and readable measures.
4. Establish relational spacing and density changes.
5. Add surfaces only for real grouping, state, selection, or interaction.
6. Add color only for hierarchy, state, brand, or data meaning.
7. Add motion only for continuity and feedback.

Open space must amplify something. Large empty areas caused by underfilled splits or delayed proof are layout defects, not sophistication.

## Define A Concrete Visual Language

Avoid adjectives without implementation consequences. Replace “premium and modern” with decisions such as:

- typography roles, weights, line-height, measure, and numeral treatment;
- palette roles and contrast behavior, including dark theme if supported;
- spacing scale, grid, container logic, and density;
- corner, border, shadow, and elevation policy;
- imagery or illustration purpose and cropping behavior;
- motion purpose, duration family, easing family, and reduced variant.

In an existing product, derive these from its tokens and representative components. Do not create a parallel system because a reference site looks appealing.

## Reject Generated-Design Reflexes

Treat these as warnings unless the content, brand, or interaction explicitly earns them:

- generic centered hero followed by an interchangeable card grid;
- every section placed in a rounded container;
- nested cards or borders used to repair weak grouping;
- pills for ordinary labels or metadata;
- arbitrary icon tiles, mixed icon styles, or icons used as filler;
- decorative gradients, glows, glass, blobs, grid textures, and fake depth;
- huge type with little information, followed by tiny muted body copy;
- equal visual weight for unequal findings or actions;
- repeated metric boxes when one comparison would communicate more;
- decorative charts, misleading scales, or color without meaning;
- stock imagery, fake screenshots, invented testimonials, or unsupported numbers;
- identical section silhouettes and uniform gaps across unrelated content;
- scroll-reveal on every section, parallax, marquees, simulated typing, and ornamental motion.

Do not answer these warnings with sterile minimalism. Create presence by committing to a focal relationship, stronger proportion, clearer typography, tighter evidence, deliberate density, and one organizing move that belongs to this content.

## Use Fast Visual Tests

- **Squint test:** blur detail; the dominant object and reading path should remain obvious.
- **Text-mask test:** hide the words; hierarchy, grouping, identity, and progression should still read.
- **Swap test:** if the layout could accept unrelated content unchanged, it is probably too generic.
- **Deletion test:** remove each decoration; restore only what carried meaning, affordance, brand, or rhythm.
- **Extremes test:** try empty, sparse, dense, short, long, and translated content before trusting the composition.
